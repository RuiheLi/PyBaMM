# Paper figure reproduction

**This folder is the main entry point for reproducing manuscript results on branch `ECdrag2`.**

- **Main text:** `main/fig_XX_*` notebooks and scripts (Figs. 3–10).
- **Supplementary:** `SI/fig_SXX_*`.
- **Shared utilities:** `shared/` (smoke tests, parity checks, `debug_long_sims.py`).
- **Outputs:** written to `../outputs/` when notebooks/scripts are run from `P3_R14` root.

See [`../README_FIGURE_INDEX.md`](../README_FIGURE_INDEX.md) for the complete figure index.
